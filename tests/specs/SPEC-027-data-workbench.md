# SPEC-027：数据工作台（数据集库、检查与查询收据）

## 背景

PurrCat 有论文库与研究记录，能把论文里的引文回指到原文。但科研里另一条同样常见的链路是
「论文里的数字」——那串数值是某个数据集算出来的，却没有任何办法回指到「哪个文件、哪一版、
按什么口径算的」。学生看到「处理组提升 12%」时无从判断这个 12% 来自哪张表、哪次筛选。

现有能力够不着：

- `Fetch` 能把 CSV 读成文本，但没有「数据集」这个概念：没有版本、没有结构画像、没有查询口径。
- `Bash` 能现场跑 Python 算一遍，但算完不留痕，下次说不清口径变了没有。
- 论文证据链只认引文，数据算出来的数字进不去。

本 spec 引入**数据集库**：导入数据文件形成「逻辑数据集 + 不可变版本」，检查给结构画像与质量报告，
查询留下**可引用的收据**。

核心约束是**不许在转述中失真**：

- CSV / TSV 的值一律按**文本**处理，`001` 就是 `001`。要做数值比较或求和，
  必须先把该列**显式**解释为数字。
- 转换失败的值**保留原文**，单独计数，绝不变成 0、也绝不变 null。
- **缺字段、显式 null、空字符串、转换失败**是四件不同的事，分开计数。
- 原文件变了或丢了就用旧数据糊弄是不允许的——检查直接报错，不给缓存预览。

## 行为

1. **数据集 = 逻辑容器 + 不可变版本**：导入文件生成一个版本；给同一个数据集导入是「加版本」。
   同名文件各自成独立数据集，只有显式「加版本」才归到一起。
2. **可用性三态**：`present` / `changed`（大小变了）/ `missing`（文件没了），按大小判断，
   不重算哈希；哈希只在检查时重算，用来确认「拿到的还是当初那一份」。
3. **检查报告**：字段画像（观察到的类型、缺字段、显式 null、空字符串、解释状态、转换失败）
   加整体质量汇总（缺字段 / 显式 null / 空字符串 / 重复行 / 转换失败 / 跳过的空行 / 解析器版本）。
4. **显式数字解释**：「预览数字」是**试算**，只算前几行并给出转不动的样例，不改任何东西；
   确认后才应用。应用后该列参与数值比较与求和。
5. **数值比较要求已解释**：在文本列上做 `>=` / `<=` 是口径错误，直接报错，不返回空结果。
6. **查询收据**：每次查询留下一条记录——数据集、版本、SHA-256、口径（问题、过滤、排序、单位、
   粒度、分母）、命中行数与可信度状态。收据可写进研究记录当作证据。
7. **面板**：内置插件 `builtin-data` 入驻中栏面板区，列出数据集与版本，展示字段画像、质量汇总
   与样本表格；「问 Agent」把数据集视图发给 Agent；检查失败时只给身份信息，并明确要求不要编造记录。
8. **不越界**：数据集库只读写自己的数据目录；导入路径先过既有文件权限检查。

## 验收标准

- [ ] AC-1：导入后有且仅有一个数据集与一个不可变版本；同名文件各自成独立数据集。
- [ ] AC-2：可用性是三态；原文件变大或消失后检查明确报错，不给旧数据。
- [ ] AC-3：CSV / TSV 的值默认按文本处理，前导零不被改写。
- [ ] AC-4：缺字段、显式 null、空字符串、转换失败分别计数。
- [ ] AC-5：显式解释为数字后，该列才能参与数值比较与求和；未解释时报错而非返回空结果。
- [ ] AC-6：转换失败的值保留原文，原文可读且单独计数。
- [ ] AC-7：每次查询留下一条收据，记录版本、SHA-256 与口径，可信度默认 needs_review。
- [ ] AC-8：面板可查看字段画像、质量汇总与样本，「问 Agent」载荷含数据集 id、版本 id 与 SHA-256。
- [ ] AC-9：新增能力不改变 `AGENT_TOOL_SCHEMA` 与 `TOOL_FUNC_MAP` 的既有条目（SPEC-003 不破）。

## 非目标

- 不做分布式查询引擎与多表连接。查询只作用在单个数据集的一个版本上。
- 不做图表生成。本轮只做结构检查与查询收据，绘图另议。
- 不做模型推断。检查与查询都是确定性的，模型只负责解释结果。
- 不做 OCR 与非表格格式的解析（Excel / Parquet / H5AD 等只保存原件）。
- 不改 Agent 主循环、工具批次与 Hook 阶段顺序。

## 风险与回滚

- 检查会重读整个原文件，大文件首次检查偏慢；上限 10 MiB / 10 万行 / 256 列，超限明确报错。
- 「解释为数字」是逐列的，用户可能忘了某列仍是文本就去做求和——因此未解释的列做数值运算
  会直接报错并提示先解释，不给悄悄算错的机会。
- 收据只记录口径与结果，不判断数字在科学上意味着什么；这一点必须留在界面上。
- 回滚：`src/data/` 与 `src/tool/data/` 都是新增，删除即回到现状；已导入的数据集留在磁盘上不影响既有功能。
