# SPEC-026：论文证据链（导入、定位与核对）

## 背景

PurrCat 有科研技能目录（SPEC-025），Agent 能找到并按需安装「怎么写文献综述」这类方法型技能，
但**方法本身不产出证据**。学生真正卡住的是另一件事：论文读完了，回答里的那句话到底在原文哪一页、
原文到底有没有这么说。

现有能力都够不着这件事：

- `Fetch` 能把 PDF 转成文本，但它是整篇一次性转换，没有分页、没有定位、无法引用回原文。
- `Bash` 里手搓 `pdfplumber` 脚本能抽出文本，但每次都要重新解析，且无法把「某句引文对应第几页」这件事
  以稳定的结构交给 Agent。
- `Memo` 能记录结论，但记下来的结论没有和原文位置绑定，事后无法回查。

结果就是 Agent 给出结论时无法回指原文，用户只能自己再翻一遍 PDF 验证——这正是科研里最不能含糊的一环。

本 spec 引入**论文库**：把 PDF 导入后分页落盘，之后 Agent 可以按页读原文、把一段引文定位到具体页码与
上下文、并核对自己的断言是否真有原文支撑。

## 行为

1. **论文库**：导入的 PDF 存放在数据目录下，每篇论文一个目录，含元数据与逐页原文。论文库是本机的，
   不随会话消失。
2. **分页原文**：导入时按页提取文本并落盘。之后读取某页原文是纯文件读，不重复解析 PDF。
3. **引文定位**：给定一段引文，能在论文原文中定位到页码、该页内的字符偏移与上下文片段。
   匹配要容忍排版造成的换行与空白差异。
4. **证据核对**：给定一条断言与（可选的）引文，判断原文是否支持该断言，返回结论、支持强度与证据位置。
   核对只依据论文自身文本，不做外部检索。
5. **Agent 工具**：论文能力对 Agent 以 native tool 形式暴露，工具名见下表。工具不引入常驻进程，
   打包后的桌面端同样可用。
6. **失败可见**：导入的 PDF 无可抽取文本（扫描件）时明确报错，不静默产出空页。引文定位不到时明确
   返回「未找到」，并给出最接近的候选页码，便于人工判断。
7. **不越界**：论文库只读写自己的数据目录，不触碰工作区其他文件；导入路径必须经用户授权。

## 工具

| 工具 | 作用 |
| --- | --- |
| `PaperImport` | 导入一篇 PDF 到论文库，解析分页原文 |
| `PaperList` | 列出论文库中的论文 |
| `PaperPage` | 读取某篇论文某一页的原文 |
| `PaperLocate` | 在论文原文中定位一段引文，返回页码与上下文 |
| `PaperVerify` | 核对断言是否有原文支撑，返回结论与证据位置 |

## 验收标准

- [ ] AC-1：导入一篇含文本层的 PDF 后，论文库多出一条记录，逐页原文可读且页数与原文一致。
- [ ] AC-2：`PaperList` 能列出已导入论文，包含 id、标题、页数。
- [ ] AC-3：`PaperPage` 返回指定页原文；页码越界时明确报错。
- [ ] AC-4：`PaperLocate` 能把引文定位到页码与上下文，且能容忍原文的换行与空白差异。
- [ ] AC-5：`PaperLocate` 找不到引文时返回未找到，并给出最接近的候选页码。
- [ ] AC-6：`PaperVerify` 能区分「原文支持」「原文不支持」「原文未提及」，并在支持时给出证据位置。
- [ ] AC-7：扫描件（无文本层）导入时明确报错，不产出空论文。
- [ ] AC-8：新增工具符合 SPEC-003 的工具注册契约，schema 与函数签名一致。
- [ ] AC-9：论文库读写限制在自己的数据目录内，不越界到工作区其他文件。
- [ ] AC-10：面板可导入 PDF：选文件或填路径都能进论文库；原生文件选择不可用时明确提示，不悬着不给反馈。
- [ ] AC-11：面板选中一段后可发送给 Agent，推送载荷含论文 id、页码与引文。

## 非目标

- 不做 OCR。扫描件需要 OCR 的，明确报错并提示用户。
- 不做外部文献检索与联网查证。核对只依据已导入论文的文本。
- 不做语义相似度判定式的「支持」判断。核对依据字面证据与规则，不引入模型推断。
- 不做 PDF 渲染与页面截图。本轮只取文本层。
- 不做论文库的多用户共享与云同步。
- 不改 Agent 主循环、工具批次与 Hook 阶段顺序。

## 风险与回滚

- PDF 解析依赖 `pdfplumber`，解析大文件会慢。导入时解析一次并落盘，之后只读文本；解析耗时不进 Agent
  的对话轮次，但首次导入仍是一次较长的工具调用。
- 文本层的抽取质量取决于 PDF 本身：双栏、表格、脚注的顺序可能不理想。核对结论标注了页码与引文，
  用户可回原文复核。
- 核对是字面规则，不判断科学正确性。它回答的是「原文有没有这句话」，不是「这个结论对不对」。
- 回滚：`src/papers/` 与 `src/tool/paper/` 都是新增，删除即回到现状；论文库数据留在磁盘上不影响既有功能。
