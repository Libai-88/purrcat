# SPEC-025：科研技能目录（按需发现与安装科研 Skill）

## 背景

PurrCat 的 Skill 体系只认**本地已安装**的 `~/.purrcat/skills/<dir>/SKILL.md`：Agent 用 `Search` 只能检索到已经放进目录的技能，`Fetch` 也只能加载本地已有的技能。

学生做科研时真正的卡点不是「没有工具」，而是「不知道该用哪个方法、参数怎么给、结果怎么验」。公开生态里已有大量成体系的科研 `SKILL.md`（生存分析、文献综述、统计检验、科研绘图、论文写作等），但 PurrCat 没有任何入口让 Agent 发现它们——用户必须自己知道仓库地址、找到 `SKILL.md`、放进 skills 目录。

同时 `install_skills_batch` 的下载路径固定为 `archive/refs/heads/{branch}.zip`，只能钉分支不能钉 commit。科研场景要求同一份方法可复现，钉不住 commit 等于钉不住方法。

本 spec 引入**科研技能目录**：一份随发行版携带的索引，描述公开第三方仓库里的科研技能及其固定 commit。Agent 检索时能看到目录里尚未安装的技能，取用时由 PurrCat 自动按需安装。

## 行为

1. **目录内容**：PurrCat 随发行版携带一份科研技能目录，条目包含技能名、上游描述、科研分类（中文）、许可状态、来源仓库、**固定 commit**、技能目录下的文件清单与 `SKILL.md` 路径。目录内容全部来自公开第三方仓库，各自带自己的许可。
2. **检索合并**：`Search(route="skill")` 返回**本地已安装技能与目录中未安装技能**的合并结果。未安装的条目带 `未安装` 标记，已安装的带目录来源信息。
3. **按需安装**：`Fetch(source="skill", name=...)` 命中一个未安装的目录技能时，PurrCat 自动完成安装后返回其 SOP 正文，Agent 无需感知安装过程。
4. **commit 固定**：按需安装按目录记录的 commit 下载，不使用分支，同一技能重复安装得到相同内容。
5. **安装范围**：按需安装只取该技能自己的目录文件，不下载整个上游仓库。目录条目自带文件清单时，安装不依赖 `api.github.com`。
6. **安装位置**：目录技能沿用既有安装路径，落到 `~/.purrcat/skills/<上游目录名>/`；安装后其内容对 `Search` 呈现为已安装。
7. **降级**：目录文件缺失、损坏或条目不合法时，检索与加载行为退化为现状（只认本地已安装技能），不报错、不阻塞 Agent。

## 验收标准

- [ ] AC-1：目录条目能被 `Search(route="skill")` 命中，且结果中能区分已安装与未安装。
- [ ] AC-2：`Fetch(source="skill")` 命中未安装的目录技能时，自动安装并返回该技能的 SOP 正文。
- [ ] AC-3：按需安装使用目录记录的 commit，而非分支。
- [ ] AC-4：目录缺失或损坏时，既有检索与加载行为不变，且不抛出异常。
- [ ] AC-5：本次改动不新增 native tool，`AGENT_TOOL_SCHEMA` 与 `TOOL_FUNC_MAP` 保持不变（SPEC-003 不破）。
- [ ] AC-6：同一目录条目重复安装幂等，结果内容一致且不残留旧文件。
- [ ] AC-7：按需安装只取该技能自己的目录文件；目录条目自带文件清单时不请求 `api.github.com`。

## 非目标

- 不做 LLM 批量翻译。目录保留上游原描述，中文提问依靠嵌入模型的多语言能力与中文分类名命中。
- 不引入第三方插件市场的上传与审核流程。
- 不改变「插件全信」的权限模型，不引入沙箱或能力白名单。
- 不改变 Agent 主循环、工具批次与 Hook 阶段顺序。
- 不把上游仓库的代码搬进 PurrCat 仓库；目录只是一份索引，技能本体始终从上游取。

## 风险与回滚

- 目录体积：条目以技能名、原描述、分类、文件清单与来源为主，千条量级为 MB 级。嵌入矩阵构建耗时随条目数增长，需放在后台且可缓存。
- 新增网络行为：`Fetch` 可能触发一次仓库下载。下载失败时应返回可读错误并保持未安装状态，不得让 Agent 陷入重试循环。
- 目录条目指向的外部仓库可能删除或改名；按 commit 安装能避免同名分支漂移，但仓库整体消失仍会导致安装失败，需在错误信息中保留来源链接以便人工排查。
- 目录质量取决于策展：分类规则与排除清单都可能滞后于上游变化，检索以语义为主、分类只是提示，个别归类不准不影响可用性。
- 回滚：删除目录文件即回到现状（本地已装技能照常工作）；`fetch_repo_zip` 的 commit 支持与定向安装都是向后兼容的新增分支。
