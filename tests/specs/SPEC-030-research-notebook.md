# SPEC-030：研究笔记（块文档、公式引擎、不可变修订）

## 背景

到 SPEC-029 为止，PurrCat 的能力各自成立：技能目录给方法，论文库给原文，数据集库给数字，
研究记录把两边对起来。但这些能力没有**落到一份能交付的文档上**——学生做完一次研究，
手上是一堆会话、几个收据、一条研究记录，而不是一篇能交出去的笔记。

Pero 的 Notebook 补的就是这一块。参考它的设计，但按 PurrCat 的形态落地，
有三处刻意不同：文档模型只有一份实现（Python），公式引擎也只有一份（Python），
面板是投影而不是第二份真相。

## 行为

1. **文档 = 块的有序列表**。块类型：`text`、`heading`、`evidence`、`data`、`table`、`finding`。
   Markdown 是投影，不单独存储。
2. **证据是块的一等公民**。`evidence` 块引用论文原文，引文必须逐字出现在那一页，
   否则整篇文档拒收；`data` 块引用一条查询收据，收据必须存在且 `status="completed"`。
3. **结论只能引用同文档内的证据块**。`finding` 的 `evidence_ids` 必须指向本文档的
   `evidence` / `data` 块，跨文档引用拒收。
4. **三层身份分开记**：块 id（文档内）、属主对象 id（论文 / 收据）、版本（commit / 收据本身）。
5. **公式引擎只有一份实现**（Python）。单元格存**公式源码**，值是渲染时的投影。
6. **错误是值，而且会传播**：引用到的格子里有 `#DIV/0!`，`SUM` 的结果也是 `#DIV/0!`，
   不能把错误跳过去——那会让「少了一个坏格子」的求和看起来像一个正常结果。
7. **循环引用产生独立的错误值**（`#CIRC!`），不能是 0——0 会被当成有效测量值混进均值和回归。
8. **易变与外部调用一律拒绝**：`NOW`、`RAND`、`PY`、`WEBSERVICE`、DDE 链接与
   `'[其它工作簿]Sheet'!A1` 返回 `#NAME?`，它们的结果不可复现。
9. **修订不可变，只追加**。提交带 `expected_revision`，对不上报冲突而不覆盖。
   每个修订记着自己的文档摘要（内容寻址）。
10. **导出有损必须说出来**：Markdown 导出会带回一份损失清单（公式不保留、格式丢失、
    证据快照不随文导出），不用有损格式悄悄替换一份完整的证据记录。

## 工具与接口

| 入口 | 作用 |
| --- | --- |
| `Notebook` 的 `list` / `read` / `save` / `export` | Agent 侧 |
| `GET /api/notebooks` | 列笔记 |
| `POST /api/notebooks/{doc_id}` | 提交修订（`expected_revision` 冲突返回 409） |
| `POST /api/notebooks/evaluate` | 算出一个文档里所有表格的值 |
| `GET /api/notebooks/{doc_id}/export` | 导出 Markdown + 损失清单 |

## 验收标准

- [ ] AC-1：文档由块组成，未知块类型与未知 schema 版本一律拒收。
- [ ] AC-2：`evidence` 块的引文必须逐字出现在所引页面，改写过的引文拒收。
- [ ] AC-3：`data` 块引用的收据必须存在且跑完。
- [ ] AC-4：`finding` 只能引用同一文档里的 `evidence` / `data` 块。
- [ ] AC-5：带 id 的块不能重号。
- [ ] AC-6：公式正确求值；单元格存的是源码而不是算出来的值。
- [ ] AC-7：错误值穿过聚合函数，不被跳过。
- [ ] AC-8：循环引用产生 `#CIRC!`，不是 0。
- [ ] AC-9：易变与外部函数返回 `#NAME?`。
- [ ] AC-10：修订只追加，旧版仍可读；修订号对不上报冲突。
- [ ] AC-11：导出带回损失清单，说明公式与证据快照的损失。
- [ ] AC-12：面板能编辑正文与表格、展示证据与收据块、显示算出来的值。
- [ ] AC-13：`POST /api/notebooks/evaluate` 不会被 `/api/notebooks/{doc_id}` 抢先匹配。

## 非目标

- 不做多人协同与实时协作。
- 不做代码执行与内核。笔记只承载文字、证据与表格。
- 不做完整的 Excel 互通（不导公式、不保格式）。
- 不做图片与附件的富媒体编辑。
- 不改 Agent 主循环、工具批次与 Hook 阶段顺序。

## 风险与回滚

- 公式引擎是自研的，语义与 Excel 不完全一致（Excel 的 `E2=E2` 报循环，Univer 某些实现报 0）。
  本实现的取舍是**宁可报错也不给一个看起来正常的数**。
- 单篇文档上限 2 MiB / 400 块；表格上限 200 行 50 列。
- 回滚：`src/notebook/` 与面板都是新增，删除即回到现状；已存的笔记留在磁盘上不影响既有功能。
